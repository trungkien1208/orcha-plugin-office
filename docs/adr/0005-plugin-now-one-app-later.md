# Easy Job ships as an Orcha plugin now and merges into one desktop app later

Installing Orcha offers Easy Job as an optional plugin (the user chooses; nothing is installed or started without consent): it ships as an Orcha plugin (open action, a server pane, optional start with Orcha) that talks to Orcha only through the socket API and CLI, while Orcha stays the engine for terminals, agents and accounts. The Owner wants a single real app later, so every change keeps the code merge-ready: the Floor stays a self-contained module (no app store or API imports inside `packages/web/src/floor`), everything Orcha-specific stays behind `packages/bridge/src/orcha/` and the reconciler, and features Orcha's terminal UI already has (accounts, hand off) are added to Orcha's socket API rather than reimplemented. The later merge is a Tauri desktop app around Orcha's server and the Easy Job UI (see `docs/plan-plugin-and-app.md`); we chose plugin-first over merging now because it ships today with no rewrite and keeps a crash in the UI away from running agents.
