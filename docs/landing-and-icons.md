# Easy Job landing: title screen + manual

The public page (root `index.html`, published to GitHub Pages by `.github/workflows/pages.yml`). Two parts:

- **Title screen**: an arcade start screen. Pixel "EASY JOB" logo, a typed tagline, the cast walking across the
  floor, Press start (or any key, or a click). It closes with an iris wipe; `#play` in the URL skips it.
- **Manual**: one screen under it (desktop does not scroll; phones do). Left: what Easy Job is and Insert coin
  (get Orcha, `orcha office install`, `orcha office`; Copy adds a credit). Right: How it plays, an animated
  product demo (the Easy Job window and Orcha's pane: a raised hand, a click, an answer), and the Boss moves.
  Bottom: house rules. The top bar links to Orcha's GitHub and Easy Job's.

No Phaser, no three.js, no bridge. Everything is sample art from the manifest; fonts are bundled
(Chakra Petch, IBM Plex Sans, JetBrains Mono). Colours come from the chair logo (rust, sage, butter). There is no
Calm switch on the page: the system's reduce-motion setting stops every animation.

## Code map (`packages/web/src/landing/`)

| File | Does |
|---|---|
| `main.tsx` | Entry: fonts, CSS, mounts `Landing`. |
| `Landing.tsx` | Reduced-motion state; Manual underneath, Intro on top until started. |
| `Intro.tsx` | Title screen (HUD, logo, tagline, Press start, parade). |
| `Walker.tsx` + `sprites.ts` | One character as a CSS sprite; polo tinted once on a canvas. Rows come from the manifest. |
| `Manual.tsx` | The one-screen manual. |
| `ProductDemo.tsx` + `product-demo.css` | The product demo, built with the Stageshow kit; see `REHEARSAL.md` beside it. |
| `BenchCanvas.tsx` | One Bench of four Agents drawn from the native sheets, status driven by the demo's script. |
| `kit/` | The parts of the Stageshow kit the demo uses (MIT, vendored as upstream wrote it: `@ts-nocheck`, excluded from Biome). |
| `Install.tsx` | Insert coin: commands, Copy with select-text fallback. |
| `data.ts` | Copy, links (Orcha site, GitHub), install steps, cast, levels, moves, house rules. |
| `art.generated.ts` | Written by `scripts/build-landing.ts` from the manifest; never edit frame numbers. |
| `landing.css` | All styles; tokens at the top. |

## Build, preview, check

```sh
bun install
bun scripts/build-landing.ts      # also rewrites favicon / og:image paths in index.html from the manifest
bun scripts/preview-landing.ts    # http://127.0.0.1:4173
node scripts/check-landing.mjs    # add --shots to save docs/review/landing-*.png
```

`check-landing.mjs` covers 390, 1024, 1440 and 2560 wide: parade drawn, Press start on screen, page inert behind
the title, any key starts, `#play` skips, the demo plays to the answer, desktop fits one screen, no horizontal overflow, no
text under 12px, Answer on the Level 2 card, Copy adds a credit and fills the clipboard with the Orcha commands,
reduced motion stills every animation and shows the demo's poster, no outbound or bridge requests.

## Icons

The native icon family is generated by `node tools/office-art/pixel-icons.cjs`; its gallery is
`/office/ui/pixel/index.html`. The Move list uses the `action-*` icons at 32px.
