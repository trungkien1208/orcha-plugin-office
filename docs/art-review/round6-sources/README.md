# Round 6 source art

The built-in image_gen tool generated bouncer.png and the three compound panoramas. Production finishing uses pngjs in tools/office-art/round6.cjs, the same native sampling, palette locking and 1px contour workflow used in Rounds 1–2. The worker extensions preserve the first nine rows and articulate the existing cast artwork; modular props, UI glyphs and effect loops are drawn on the native grid. No image-generation API or CLI was used.

Run sections A, B, C, D in order, followed by round6-finalize.cjs and round6-validate.cjs. Contact sheets are docs/art-review/round6-{a,b,c,d}.png.

The live checklist consolidated three separate action icons into act-icons.png during production, reducing its checker total from 106 to 104. The original three files are delivered as compatibility assets as well.
