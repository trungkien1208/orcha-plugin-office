# Party Agent pixel icon references

Native 16px PNG artwork from the Owner's earlier Party Agent project, used as the visual reference for Easy Job's icons. Retained here as editable generator inputs. No Party Agent runtime or application code is included.

`node tools/office-art/pixel-icons.cjs` assembles the curated set, remaps the legacy fallback colours into the same mint/peach/lavender palette, registers the sheet in the art manifest and emits its TypeScript index.
